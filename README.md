# So sánh Content Box và Border Box

Ba card có width 280, height 150, padding 20, border 5, margin 20. Card đầu content-box có border box thực tế 330 × 200, hai card còn lại 280 × 150. Nếu tính thêm margin hai bên, chiều rộng không gian là 370 và 320 px.

## Chạy
Mở index.html trong trình duyệt.

## Kiểm tra
Đã mở ở 375, 768, 1440 px và kiểm tra box-sizing, padding, border, margin trong trình duyệt. Ảnh result.png là kết quả chạy nếu bài yêu cầu nộp ảnh. Kích thước CSS có thể được làm tròn nhẹ theo mức zoom trình duyệt.
